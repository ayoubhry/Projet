# Hub

Portail centralisé regroupant mes projets web, applications et études de cas.

> Lien : https://ayoubhry.github.io/hub/

## 🚀 Projets inclus

- **Portfolio** : Présentation personnelle et vitrine de compétences.
- **McDo Tracker** : Application de suivi et d'analyse de données.
- **Xbox Breakdown** : Étude visuelle et technique de composants.
- **Docs** : Espace de documentation des projets.

## 📁 Structure

```text
Hub/
├── assets/img/   # Captures et visuels des projets
├── css/          # Styles (style.css)
├── js/           # Données et scripts (data.js, main.js)
└── index.html    # Page principale
```

## 💻 Utilisation

Cloner le dépôt et ouvrir `index.html` dans un navigateur :

```bash
git clone https://github.com/ayoubhry/hub.git
cd hub/Hub
```

## 🛠️ Stack

HTML5 • CSS3 • JavaScript (ES6+)
